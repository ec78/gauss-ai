# Workflows

This directory documents implementation-agnostic workflows for the GAUSS AI framework.

## Available Workflows

- `code-assistant-response.md` - Standard response workflow for the GAUSS Code Assistant.
- `command-documentation-retrieval.md` - Hybrid command documentation strategy using official docs plus a small curated cache.
- `knowledge-loading.md` - Knowledge source resolution and local-first retrieval policy.
- `manual-evaluation.md` - Manual benchmark evaluation process and result template.
- `native-command-selection.md` - Native GAUSS command selection, documentation retrieval, and manual implementation decision workflow.
- `retrieval-backed-response-pattern.md` - Standard response structure for answers that rely on command-specific retrieval evidence.

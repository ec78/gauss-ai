# Evaluation Runs

## Purpose

This directory stores manual or automated evaluation run records for GAUSS AI agents. Each run records how an agent performed against benchmark prompts at a point in time.

## Naming Convention

Recommended file names:

```text
YYYY-MM-DD-code-assistant-v0.2.0.md
```

or:

```text
YYYY-MM-DD-code-assistant-manual-run-001.md
```

## What to Record

- Date.
- Evaluator.
- Agent version.
- Prompt IDs.
- Response summaries.
- Rubric scores.
- Blocking issues.
- Suggested improvements.
- Follow-up actions.
- Pass / needs revision / fail decision.

## Notes

Evaluation runs should be committed when they document meaningful framework behavior. Temporary scratch evaluations may remain uncommitted.

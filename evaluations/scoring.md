# Scoring

Use this rubric to evaluate agent responses for GAUSS-related tasks.

## Criteria

### Correctness

Does the response solve the task accurately and avoid unsupported claims?

### GAUSS Fluency

Does the response use GAUSS syntax, idioms, and conventions appropriately?

### Repository Awareness

Does the response respect local project structure, files, and documented conventions?

### Clarity

Is the response easy to understand, actionable, and appropriately concise?

### Safety

Does the response avoid destructive actions, invented source content, and hidden assumptions?

## Suggested Scale

- `5` - Excellent: correct, complete, idiomatic, and clearly explained.
- `4` - Good: mostly correct with minor gaps.
- `3` - Adequate: useful but incomplete or somewhat generic.
- `2` - Poor: significant issues or missing key requirements.
- `1` - Failing: incorrect, unsafe, or unusable.

# ADR-0001: Project Vision

## Status

Accepted

## Context

The repository needs a clear architectural direction for building AI support around GAUSS programming, documentation, education, econometrics, and product workflows.

## Decision

GAUSS AI will be organized as an open framework for specialized, knowledge-grounded, tool-assisted, and continuously evaluated AI agents focused on the GAUSS ecosystem.

## Consequences

- Repository structure should favor reusable framework components over one-off prompts.
- Significant architectural decisions should be recorded as ADRs.
- Future work should preserve the distinction between agents, expertise, knowledge, tools, workflows, and evaluations.

# Best Practices

Practices the Education Expert should promote across agents that consult it.

- Start with the learner outcome, not the content list (`BODY_OF_KNOWLEDGE.md`, Learning Objectives).
- Identify prerequisites explicitly before sequencing content (`BODY_OF_KNOWLEDGE.md`, Instructional Sequencing).
- Sequence from concrete to abstract where useful (`BODY_OF_KNOWLEDGE.md`, Instructional Sequencing).
- Scaffold complexity gradually, fading support as competence increases (`BODY_OF_KNOWLEDGE.md`, Scaffolding).
- Use worked examples before open-ended practice (`BODY_OF_KNOWLEDGE.md`, Scaffolding, Practice Design).
- Include checks for understanding throughout, not only a final test (`BODY_OF_KNOWLEDGE.md`, Feedback and Assessment).
- Provide feedback criteria, not just a correct/incorrect signal (`BODY_OF_KNOWLEDGE.md`, Feedback and Assessment).
- Design practice that matches the stated objectives (`BODY_OF_KNOWLEDGE.md`, Practice Design).
- Manage cognitive load — introduce one new idea at a time where practical (`BODY_OF_KNOWLEDGE.md`, Cognitive Load).
- Surface common misconceptions explicitly rather than hoping they don't arise (`BODY_OF_KNOWLEDGE.md`, Misconception Handling).
- Include remediation paths for learners who don't grasp a concept the first time (`BODY_OF_KNOWLEDGE.md`, Feedback and Assessment).
- Distinguish reference docs (Documentation Expert territory) from lessons (this expert's territory) (`EXPERT.md`, Relationship to Documentation Expert).
- Keep exercises realistic but bounded in scope (`BODY_OF_KNOWLEDGE.md`, Practice Design).
- Avoid unsupported syntax or methodology claims inside examples and exercises (`EXPERT.md`, Relationship to GAUSS Language Expert, Relationship to Econometrics Expert).
- Label pseudocode clearly whenever an example is not verified GAUSS syntax (`EXPERT.md`, Response Behavior).
- Use documentation as supporting material, not a replacement for instruction (`BODY_OF_KNOWLEDGE.md`, Relationship to Documentation Expert).
- Avoid treating onboarding education as product strategy (`EXPERT.md`, Relationship to future Product Expert).
- Align assessment with the stated learning objectives (`BODY_OF_KNOWLEDGE.md`, Feedback and Assessment).

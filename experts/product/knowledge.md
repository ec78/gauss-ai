# Product Knowledge

This file is retained as a compatibility placeholder.

The active Product Expert body of knowledge is maintained in:

- `experts/product/BODY_OF_KNOWLEDGE.md`

Use `BODY_OF_KNOWLEDGE.md` for product scope, user problem framing, workflow-fit reasoning, value proposition guidance, product positioning, prioritization tradeoffs, product assumptions, adoption risks, discovery questions, and common product anti-patterns.

This file should not be treated as a separate or competing knowledge source. Nothing else in this repository references this file by path as of `v0.17.0` (`planning/v0.17.0-product-expert-foundation.md`); it is kept, rather than deleted, only to avoid a silent gap for a reader expecting every expert directory to have a `knowledge.md`, mirroring the disposition already applied to `experts/econometrics/knowledge.md` in `v0.11.0`, `experts/gauss-language/knowledge.md` in `v0.12.0`, `experts/software-engineering/knowledge.md` in `v0.14.0`, `experts/documentation/knowledge.md` in `v0.15.0`, and `experts/education/knowledge.md` in `v0.16.0`.

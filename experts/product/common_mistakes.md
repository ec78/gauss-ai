# Common Mistakes

Common AI and user failure modes the Product Expert should help agents avoid.

- Starting with features instead of user problems (`BODY_OF_KNOWLEDGE.md`, User Problem Framing).
- Treating a useful-sounding idea as validated without user evidence.
- Confusing user demand with statistical correctness — a feature users want is not automatically methodologically sound (`EXPERT.md`, Relationship to Econometrics Expert).
- Confusing documentation/training quality with product value — good docs or training can support adoption but do not prove a feature is valuable (`EXPERT.md`, Relationship to Documentation Expert, Relationship to Education Expert).
- Ignoring time-to-value when reasoning about a feature's adoption prospects.
- Ignoring workflow fit and evaluating a feature in isolation from how users actually work.
- Overbuilding before validating the underlying hypothesis.
- Unclear success criteria that can't actually be checked later.
- Vague customer segment ("everyone") instead of a specific target user.
- No adoption-barrier analysis before recommending that a feature ship.
- Conflating product strategy with implementation details (`EXPERT.md`, Relationship to GAUSS Language Expert).
- Using product framing to bypass evidence requirements — a compelling user story is never a substitute for GAUSS syntax evidence, statistical validity, maintainability judgment, documentation accuracy, or learning-design soundness.
- Treating a polished demo as proof of value.
- Failing to identify assumptions, so a recommendation reads as more certain than it actually is.
- Prioritizing without stated tradeoff criteria.
- Claiming market proof without evidence — a plausible narrative is not validated demand.
- Treating product urgency as proof that a design/maintainability risk is acceptable (`EXPERT.md`, Relationship to Software Engineering Expert).
- Treating adoption as guaranteed because training or onboarding exists — good training can support adoption but does not guarantee it (`EXPERT.md`, Relationship to Education Expert).

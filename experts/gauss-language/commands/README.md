# Curated Command Notes

This folder is an optional curated cache of short GAUSS command reference notes.

It is not a documentation mirror. Do not create one file per GAUSS command by default, and do not copy full official documentation pages into this repository.

Use this folder only for high-value, failure-prone, or frequently evaluated commands where a short verified note helps the GAUSS Code Assistant avoid hallucinated syntax or repeated retrieval work.

Official GAUSS command-specific documentation remains authoritative for exact syntax, inputs, outputs, examples, return values, and version behavior. If a cached note conflicts with official documentation, official documentation wins.

Each command note should include:

- Command name.
- Why the note exists.
- Official source.
- Last verified date or repository state.
- Short verified syntax summary, if available.
- Important caveats.

If exact command syntax is not verified, the note should say that command-specific documentation must be retrieved before production syntax is provided.
